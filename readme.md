# Hangman Game

A simple text-based Hangman game made with Python.

The computer picks a random word and you guess it one letter at a time. You can make 6 wrong guesses before you lose.

## How to run

1. Install Python 3
2. Download `hangman.py`
3. Open a terminal in the folder and run:

```
python hangman.py
```

## How to play

- Type one letter and press Enter
- Correct letters show up in the word
- Wrong guesses reduce your tries (6 in total)
- Guess the full word to win

## Concepts used

`random`, `while` loop, `if-else`, strings, lists
